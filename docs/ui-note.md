# UI 说明：食光

- **谁在什么时刻打开**：给下班后做两菜一汤的人。
- **首屏任务句**：用现有食材，做一顿饭。
- **主操作**：按「报食材和时间 → 排锅具与灶眼 → 照着步骤做完」推进；首屏先给输入和主按钮，结果区在下方或右侧。
- **主信息结构**：厨房操作牌；对比、时间线、原文与修订、队列或价签按任务选择，而不是通用卡片堆叠。
- **三种状态**：空状态指到第一步；已有内容显示结果、来源/计算依据和导出入口；失败或待确认时保留已填内容，并在原位置说明缺什么。
- **视觉原型**：厨房操作牌。底色、强调色、圆角、边框和数字字体都按该任务重定，遮住产品名后仍能从布局看出用途。
- **解释**：给下班后做两菜一汤的人：先说有啥、几人吃、还剩多久和过敏项，再把菜排成共用锅具和灶眼的顺序。
